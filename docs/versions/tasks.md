## 与设计文档的差异（实现时调整）

1. **子测试不预先绑定运行时**改为**创建时轮转分配，空闲运行时可以领走别的运行时名下仍在排队的子测试**。`runs.runtime_id` 是外键，写 0 会被拒绝；这样既保证外键完整，也能让快的机器多跑。
2. **子测试的 `branch`** 存用户填的 ref 原文（报告里显示），实际锁定靠 `pin_ref` + `pin_sha`：`pin_ref` 为空表示用户填的是 SHA，只按 commit 拉取。
3. **「部分无法验证」的成员也可以沉淀用例**（只要没有未通过）。回归里这类条目通常是因为缺少环境或凭据，长期回归仍然有价值。
4. **版本释放后仍保留**，只读；已发布版本里的 issue 再次进入新版本时，旧版本的成员记录保留（`repo_id` 取负以释放唯一约束），避免历史矩阵丢失。
5. **回归子测试不在「验收测试」列表里显示**，只在版本页查看，避免把列表刷满。手动「重新回写 Linear」仍可用。
