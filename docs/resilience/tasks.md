## 与设计文档的差异

1. **重试间隔按秒存**（`stage_retry_delay_seconds`），页面按分钟展示。分钟粒度没法做自动化测试，也不方便用户调小。
2. **重试改为事件驱动**：安排重试时直接挂定时器，到点推进。只靠每分钟一次的看门狗会让短间隔的重试白等。
3. **交叉模型失败不走这套重试**：仍由流水线原有的「改用主 harness 再试一次」处理，避免两套机制叠加把尝试次数算乱。
4. **续跑不复制失败的阶段**：只复制 `ok` 和 `skipped` 的记录，失败的阶段由流水线重新创建。
